# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/eishal-web-dev/MFZ-website-clone.git

cd MFZ-website-clone
```

---

## Install Frontend

```bash
npm install
```

---

## Install Backend

```bash
cd server

npm install
```

---

# ⚙ Environment Variables

## Backend (.env)

```env
MONGODB_URI=

CLIENT_URL=

ADMIN_EMAIL=

JWT_SECRET=

JWT_EXPIRES_IN=7d

EMAIL_HOST=

EMAIL_PORT=

EMAIL_USER=

EMAIL_PASS=

EMAIL_FROM=
```

---

## Frontend (.env)

```env
VITE_API_BASE_URL=

VITE_GOOGLE_CLIENT_ID=
```
